# アフィリエイト広告コード置き場

ASP（A8.net等）で発行された広告コード（HTMLタグ）を、スロット名と同じファイル名で
このフォルダに置くと、サイトの該当箇所に表示される。ファイルが無いスロットは非表示。

| ファイル名 | 表示場所 |
| --- | --- |
| `fx-page.html` | FX一覧ページとFX各銘柄の詳細ページ（チャートの下） |
| `crypto-page.html` | 暗号資産一覧ページと暗号資産各銘柄の詳細ページ（チャートの下） |
| `post-bottom.html` | 朝刊・夕刊の記事末尾（免責事項の上） |
| `us-stocks.html` | 米国株ページの末尾 |

- 広告コードはASP管理画面からコピーしたものをそのまま貼り付けてよい
  （`<a>` + `<img>` 形式・スクリプト形式どちらも可）。
- 「PR」表記は枠側で自動付与される（景表法ステマ規制対応）。
- 複数バナーを並べたい場合は1ファイル内に複数タグを書いてよい。
